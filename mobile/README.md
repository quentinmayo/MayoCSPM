# MayoCSPM mobile

Native iOS and Android companion for MayoCSPM 0.2+. Apache-2.0 under the repository
root license. Inventory, findings, exposure context, role-checked scans, workspace
switching, secure device sessions, and optional Okta system-browser sign-in.

```sh
npm ci
npm run typecheck
npm run lint
npm test
npm run audit:review
npx expo-doctor
npm run ios      # Xcode + CocoaPods
npm run android  # Android Studio + SDK + JDK
```

[Build, self-hosting, security and feature limits](../docs/MOBILE.md) ·
[Okta configuration](../docs/OKTA.md). Native directories are generated by Expo;
never commit signing material. Store publication requires your developer accounts.
